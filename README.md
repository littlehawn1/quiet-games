# Quiet Games

Ad-free games that run in the browser and work offline: **Sudoku** (Classic, Killer and
Samurai, with hints that teach), **Words** (swipe letters to fill a crossword), **Eight Goals**
(a rummy-style card game against the computer), **Rising Blocks** (swap blocks before the stack
reaches the top, including versus the computer and a 3D cylinder board) and **Mahjong Solitaire**.

Play: open `index.html`, or the GitHub Pages site for this repository.

No ads, no tracking, no accounts. Progress is saved on your own device.

Word list: SCOWL by Kevin Atkinson (see `words-license.txt`). Fonts: Lexend and Bricolage
Grotesque under the SIL Open Font License (see `fonts/OFL.txt`).
